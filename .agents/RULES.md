# Project rules
- Vanilla HTML/CSS/JS only, no build step, no frameworks. Static hosting (Vercel/Netlify/GH Pages).
- Chrome must be real Win98: no emoji, rounded corners, shadows, fades, modern fonts. Title-bar gradient + Start banner gradient only.
- Creativity goes into content (files, lore, eggs), never chrome. Lore is satire; EIPSTEIN is a protocol, never a real person.
- All icons = canvas pixel art (js/icons.js); all sounds = Web Audio (js/sound.js). No external assets.
- Commit after each subphase; stage only your own files (teammates push to main).
